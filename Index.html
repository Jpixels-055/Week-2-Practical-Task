What i learned

What does the action attribut do?

The Action attribute identifies the destination to which the form submission is sent.

What does the method attribute do?

The Method attribute specifies how the browser should submit the form data.

Why is GET commonly useful for a search form?

The GET method appends the form data to the URL as a query string, making it visible and shareable. This is useful for search forms because it allows users to bookmark or share the search results.

Why might POST be used for a registration form?

The POST method sends the form data in the body of the HTTP request, making it more secure and suitable for sensitive information like passwords. This is why POST is often used for registration forms where user credentials are submitted.

Does using POST automatically make information secure? Explain why or why not.

No, using POST does not automatically make information secure. While POST sends data in the body of the HTTP request, making it less visible than GET, it does not inherently encrypt the data. Security depends on additional measures like HTTPS encryption and proper server-side handling of the submitted data.
